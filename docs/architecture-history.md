# QueryTube Architecture History

This page records reported architecture milestones before and during the move to the current Vercel-based setup. It is a retrospective history, not a description of the current architecture and not evidence that these earlier changes went through OpenSpec.

> Source: project owner recollection shared on 2026-10-02. Dates for the milestones below were not provided.

## Reported sequence

1. **Google AI Studio** — The initial application work was done through Google AI Studio.
2. **Publish to Cloud Run** — An early version was published and hosted on Cloud Run.
3. **GitHub synchronization** — GitHub synchronization was set up during this earlier workflow. The exact mechanism and timing were not provided.
4. **Move to Vercel** — The project later moved to Vercel, which the project owner identifies as the current hosting platform.

The repository also retains a [historical Vercel migration implementation plan](archive/vercel-migration-implementation-plan.md). That plan documents migration planning and repository-state assessments; it is separate from this owner-reported chronology.
